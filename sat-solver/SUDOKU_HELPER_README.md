# 数独助手使用说明

## 📖 功能概述

数独助手是一个基于终端的交互式数独游戏工具，集成了SAT求解器，提供智能提示和验证功能。

## 🚀 编译运行

### Windows系统
```cmd
build_helper.bat
bin\sudoku_helper.exe
```

### Linux/Ubuntu系统
```bash
chmod +x build_helper.sh
./build_helper.sh
./bin/sudoku_helper
```

## 🎯 主要功能

### 1. 基本操作
- **输入数字**: `A1 5` - 在A1位置填入数字5
- **清除数字**: `B3 0` - 清除B3位置的数字
- **显示数独**: `show` - 显示当前数独状态

### 2. 智能提示功能
- **`hint1`** - 找出一个填错的位置并提示正确答案
- **`hint2`** - 随机提示一个空位置的正确数字
- **`check A1`** - 检查A1位置是否填错

### 3. 答案相关
- **`solution`** - 显示完整答案
- **`validate`** - 验证当前填入的数字是否都正确
- **`submit`** - 提交答案并进行完整检验

### 4. 文件操作
- **`load puzzle.txt`** - 加载数独文件
- **`save game.txt`** - 保存当前游戏状态
- **`generate 1/2/3`** - 生成简单/中等/困难题目

### 5. 其他命令
- **`help`** - 显示帮助信息
- **`status`** - 显示游戏状态统计
- **`quit`** - 退出游戏

## 📋 数独文件格式

数独文件应该是9行，每行9个数字，用空格分隔，0表示空位：

```
5 3 0 0 7 0 0 0 0
6 0 0 1 9 5 0 0 0
0 9 8 0 0 0 0 6 0
8 0 0 0 6 0 0 0 3
4 0 0 8 0 3 0 0 1
7 0 0 0 2 0 0 0 6
0 6 0 0 0 0 2 8 0
0 0 0 4 1 9 0 0 5
0 0 0 0 8 0 0 7 9
```

## 🎨 界面说明

数独网格显示采用颜色标识：
- **蓝色数字** - 题目给定的数字（不可修改）
- **黄色数字** - 用户输入的数字
- **绿色数字** - 正确的用户输入
- **红色数字** - 错误的用户输入

坐标系统：
- 行：A-I（从上到下）
- 列：1-9（从左到右）
- 例如：A1表示左上角，I9表示右下角

## 💡 使用技巧

1. **初学者建议**：
   - 先用 `generate 1` 生成简单题目练习
   - 遇到困难时使用 `hint2` 获取提示
   - 用 `validate` 检查当前进度

2. **进阶用户**：
   - 使用 `hint1` 找出错误位置
   - 用 `check` 命令验证特定位置
   - 挑战困难模式 `generate 3`

3. **调试模式**：
   - 使用 `solution` 查看完整答案
   - 用 `status` 查看统计信息

## 🔧 集成SAT求解器

当前版本使用简单的回溯算法作为临时实现。要集成真正的SAT求解器：

1. 修改 `solve_sudoku_internal()` 函数
2. 调用现有的数独转CNF函数
3. 使用 `solve_sat()` 进行求解
4. 从 `Assignment` 结果中提取数独解

## 🐛 故障排除

- **编译错误**：确保已安装g++编译器
- **文件加载失败**：检查文件路径和格式
- **显示异常**：确保终端支持ANSI颜色代码
