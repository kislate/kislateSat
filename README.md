# SAT求解器 - 华中科技大学(HUST)2025数据结构课程设计

## 项目简介

本项目是华中科技大学2025年数据结构C语言课程设计的SAT求解器实现。项目基于DPLL算法，结合MOM和JW启发式策略，实现了高效(并非高效)的布尔可满足性问题求解器，并提供了数独游戏生成与求解功能。

### 主要特性

- **高效SAT求解**: 基于DPLL算法，支持单元传播和纯文字消除
- **智能启发式**: 集成MOM和JW启发式策略进行变量选择优化
- **数独求解器**: 将数独问题转换为SAT问题进行求解
- **交互式数独游戏**: 提供数独谜题生成和交互式游戏界面
- **美观界面**: 采用Unicode字符绘制的终端界面
- **多平台支持**: 支持Windows和Linux系统

## 技术架构

### 核心算法
- **DPLL算法**: 经典的SAT求解算法
- **单元传播**: 自动推导单元子句的赋值
- **纯文字消除**: 优化搜索空间
- **MOM启发式**: Maximum Occurrences on clauses of Minimum size
- **JW启发式**: Jeroslow-Wang启发式策略

### 数据结构
- **动态数组**: 高效的CNF公式存储, 并非
- **赋值栈**: 支持回溯的变量赋值管理, 并非
- **子句索引**: 快速访问和更新子句状态, 并非

#### 5.2 游戏操作

**菜单选项**:
1. **填写数字**: 输入位置和数字，如`A1 5`
2. **随机提示**: 系统随机给出一个位置的答案
3. **指定提示**: 给出指定位置的提示，如`A1`
4. **显示答案**: 临时显示完整解答
5. **错误检查**: 检查当前填写是否有错误

- 清除数字: `A1 0` (A行1列清除)

- ❌ 错误填写在检查时会标记为`X`

## 性能特点

### 算法优化
- **启发式策略**: MOM和JW策略显著提升求解效率, MOM没用上
- **单元传播**: 自动推导减少搜索空间
- **纯文字消除**: 进一步优化变量选择
- **实际表现**: 一坨屎, 大部分代码都是应付老师的垃圾菜单美观

### 性能数据
- 小规模问题 (<100变量): 通常在1ms内完成
- 中等规模问题 (100-1000变量): 几十毫秒到几秒
- 数独问题 (729变量): 通常在50ms内完成
- 谁信谁傻逼

## 算法详解

### DPLL算法核心流程
1. **单元传播**: 处理单元子句，强制赋值
2. **纯文字消除**: 删除只以正或负形式出现的变量
3. **变量选择**: 使用MOM/JW启发式选择分支变量
4. **递归分支**: 尝试True/False赋值
5. **回溯**: 遇到冲突时撤销赋值

### 启发式策略比较
- **MOM策略**: 选择在最小子句中出现最多的变量
- **JW策略**: 基于子句长度加权的变量选择
- **组合策略**: 根据问题规模动态选择最优策略
